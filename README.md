# Data Cleansing & Sales Analysis Project (SQL)

## Project Overview
This project demonstrates my ability to handle raw, "messy" data and transform it into actionable business insights. Using SQL, I performed data cleaning, handled missing values, and created a final reporting view to track operational KPIs.

## Key Skills Demonstrated
* **Data Cleansing:** Standardizing date formats and handling NULL values.
* **Aggregations:** Calculating Total Revenue, Average Order Value (AOV), and Churn indicators.
* **CTEs & Joins:** Using Common Table Expressions for readable and efficient queries.
* **Business Logic:** Applying audit-style verification to ensure data integrity.

## How to use
The `analysis.sql` script contains the full pipeline from raw data to the final dashboard-ready view.
